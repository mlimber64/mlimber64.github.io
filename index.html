Chi sono

Sono uno sviluppatore full stack di Salerno. Mi piace trasformare un problema complesso in un sistema semplice da capire, da testare e da far crescere.

Lavoro con Java e Spring Boot, con .NET, con Angular e con Flutter. Nei miei progetti curo ogni dettaglio: architettura a livelli, messaggistica con eventi, pipeline di CI, analisi della qualità del codice e decisioni di progetto documentate.

Progetto principale

Gestione Ordini

Microservizi per ordini, magazzino e notifiche

Sistema di gestione degli ordini a microservizi: catalogo, magazzino e ordini con riserva atomica delle giacenze, eventi su Apache Kafka con transactional outbox e notifiche in tempo reale.

  • CI con test, SonarCloud e immagini pubblicate su GHCR
  • Decisioni di architettura documentate in ADR
  • Login con JWT o Keycloak (OIDC) e CDC opzionale con Debezium
  • Java 25
  • Spring Boot 4
  • Angular 22
  • PostgreSQL 18
  • Kafka
  • Docker

Repository privato

EventHub

Prenotazione e vendita di biglietti con microservizi .NET

Piattaforma per prenotare e vendere biglietti di eventi, a microservizi con .NET 9, PostgreSQL e RabbitMQ. L'acquisto attraversa quattro servizi con database diversi e si risolve con una saga, Outbox/Inbox e rimborsi compensativi.

  • Saga di acquisto con rimborsi compensativi, coperta da test end-to-end
  • Cinque servizi con database separati e Gateway YARP con rate limiting
  • JWT con refresh token rotanti, CQRS con MediatR e CI su GitHub Actions
  • .NET 9
  • RabbitMQ
  • PostgreSQL
  • Angular
  • YARP
  • Docker
